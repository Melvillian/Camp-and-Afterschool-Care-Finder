HOW TO HELP

This Sheet feeds a website that helps Vermont families find summer camps. Each camp posts its dates and prices on its own web page. We need a person to read that page and make sure our list matches it. Ten minutes helps.

THE TABS
- Tasks: the to-do list. Each row is one small job for one camp.
- Drafts: the camp listings we are working on, one row for each camp session. A row gets here in one of two ways: a computer read the camp's page and wrote a first draft, or a volunteer typed it in. Either way it is only a draft. Nothing in this tab is on the website yet. Each row belongs to a task (its task_id matches a row in Tasks). When you have compared a row with the camp's page and marked it in the review column, a maintainer reads it and puts it on the website.
- Orgs: facts about the organization itself, not one session: when registration opens, financial aid, and the website.

1. PICK A TASK
Open the Tasks tab. Find a row where status says open. Type your first name in claimed_by, type today's date in claimed_on (like 2027-01-12), and change status to claimed.

THIS SHEET IS PUBLIC. Anyone with the link can read everything in it, including what you type in claimed_by and volunteer_notes. Initials or a nickname are fine. Do not type an email address, a phone number or anything else private.

CAN'T TYPE IN A CELL? Only people a maintainer has added can edit. Sign in to Google and press "Request edit access" at the top of the Sheet. A maintainer will add you.

2. DO IT
The kind column says what to do:
- find_page (2 min): the camp's web page is missing or broken. Search for their summer camp page. Paste its address into volunteer_notes.
- check_draft (10 min): open the Drafts tab and find rows with your task_id. Open the source_url page and compare each row with it.
- check_changes (10 min): the camp's page changed. Compare the Drafts rows with the page and fix what is out of date.
- enter_new (45 min): the page could not be read by computer. Read it yourself and add one Drafts row for each camp session. Copy the task_id and org_id from your task's row, leave row_id blank, and fill in what the page says.

Example. The source_quote says: "Art Camp, July 5-9, 9am to 3pm, $250." Your row should say: program_name Art Camp, start_date 2027-07-05, end_date 2027-07-09, start_time 09:00 AM, end_time 03:00 PM, cost_per_week 250.

3. CHECK THE ORGS TAB
If your task has a row in the Orgs tab (find it by task_id), check it against the page: when registration opens, whether financial aid is offered, and the website. Fix what is wrong and fill in what is blank. Leave a cell blank if the page does not say.

4. MARK EACH ROW
In the review column of every Drafts row type one of:
- ok (it matches the page)
- fixed (you changed something to match the page)
- delete (the page does not have this camp)

5. FINISH
Change status in Tasks to done.

RULES
- Leave a cell blank when the page does not say. Never guess.
- Type dates as 2027-07-06.
- Do not add, delete or reorder columns.
- Not sure? Write your question in volunteer_notes on your task's row and set status to needs_help. A maintainer reads these every week.
